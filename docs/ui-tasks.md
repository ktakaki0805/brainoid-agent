# タスクの画面

BA-UI-06 / FR-008 / AC-008 は、スマホと共有ディスプレイの認証済みテナント画面に[タスク一覧](../packages/ui/src/tasks/view.tsx)を追加する。[タスクAPI](tasks.md)の正本だけを表示し、会話の成功文やtool表示から状態を変更しない。API・通知・リマインダーの契約は変更しない。

## 期限・担当・状態

一覧は個人/共有とopen/done/cancelledで絞り込める。期限なし・担当未指定も明示する。表示タイムゾーンは利用者がこの画面で選び、初期値がブラウザー設定であることを表示する。これは画面内だけの選択で、ユーザープロフィールのtimezoneを取得・更新する機能ではない。タスク作成時の任意のtimezoneとは独立し、表示先の変更は保存された時点を変更しない。テナントやページを離れると表示設定も初期化する。

期限入力は秒とUTCオフセットを含む日時（例 `2026-11-01T01:30:00-04:00`）を必要とする。夏時間の重複時刻を推測せず、`-05:00`なら別の時点となる。存在しない日付・オフセットなし・未知のオフセット`-00:00`は送信しない。任意のIANAタイムゾーンは別保存する説明を添え、空欄は推測して補完しない。サーバーもIANA名・日時・担当者の現在権限を検査する。

作成は初期状態open。担当者は同じテナントの有効なopaque UIDをそのまま送信し、指定によって個人タスクの閲覧権を与えない。編集はTaskPatchで認められる題名・状態・期限のみ。空の期限は`due_at:null`で削除する。完了・取消・再開は編集フォームの明示選択と保存で行う。担当者・記録したtimezone・公開範囲・表示先は編集できない。共有タスクの作成者を公開DTOから推測せず、書込可否はサーバーが決める。

## 保存・競合・失効

[コントローラー](../packages/ui/src/tasks/controller.ts)は新規作成201・更新200とTask本体・ETag・対象ID・tenant・versionを照合してから保存結果を表示する。保存中・入力拒否・通信失敗・412の未保存doneを一覧へ反映しない。保存後はcursorをリセットして現在条件の一覧を取り直し、状態条件から外れる結果も通知に現在状態を表示する。複数ページはstatus/limitを固定し、重複ID・cursor循環・状態不一致を拒否する。読取と書込は直列で、古い読取が後の保存を上書きしない。

応答喪失は受付不明として入力を凍結し、同一body・Idempotency-Key・If-Matchで再確認する。receipt再送が後の編集を反映した正本を返す場合も、その現在状態を表示する。412は入力と編集開始時・再取得した最新版を比較表示し、利用者が最新版を確認してから新しい版とkeyで保存する。最新版が一覧の状態条件から外れていても比較できる。入力を捨てて閉じることもできる。選択時の詳細取得が一覧より新しければ、その題名・期限・状態・版で一覧を更新する。状態条件から外れた行は除き、編集フォームには取得した正本を保持する。フォームを閉じても古い一覧へ戻さない。

本人未確認の共有ディスプレイはsharedかつshared_displayだけを表示し、コントローラーでも全書込を拒否する。スマホ操作またはtasks scopeを許可する個人セッションを案内するが、この共有画面を個人セッションの書込画面へ変更しない。UID/tenant変更・サインアウト・pagehideで本文・入力・再送要求を消去する。現在の401は一度だけtoken更新して同じ要求を再送し、継続する401と403/404はセッションを閉じる。古い画面の遅い応答は新しいcontextを失効させない。

## 検証・切戻し

[コントローラー試験](../tests/test_ui_tasks.mjs)はAI成功文の負例、未保存done、再送・競合・期限・ページング・認可と応答競合を検証する。[Chromium試験](../tests/ui/tasks_browser.mjs)はスマホ390×844とディスプレイ1280×800、IANA表示切替、夏時間の時点、実際のbfcache復帰と消去を確認する。[実HTTP/Firestore試験](../tests/emulator/test_ui_tasks_integration.py)は生成SDKとコントローラーを既存APIへ接続し、正本・イベント・412・現在版receiptを確認する。実施結果は[作業ログ](implementation-log.md)へ記録する。

実行は `mise run test` と `mise run check`。ブラウザーは専用証跡ディレクトリを`UI_ARTIFACTS`、既存Chromiumを`UI_CHROMIUM`で指定して `mise exec -- node tests/ui/tasks_browser.mjs` を実行する。実機Pi・署名mobile・実providerの検証は含まない。依存追加・schema変更・データ移行はない。切戻しはUIを以前の版へ戻す。保存済みタスクとAPIの冪等receiptを削除しない。
